## 本轮结果（59 题）

- 模板题 50 道：平均召回 **100.0%** · 平均精确 **49.5%**
- 手写题：枚举 100%/86.8%，年份 100%/97.0%，人物 100%（11 源），变体/单事实必中 ✓，闲聊/域外/对抗全部 0 来源或正确拒答
- 生成侧：59 题回答全德语 · 零编造引用（护栏生效） · 零 intern 泄漏
- 人工审阅表：`test/review-latest.md`（59 题，待评分）

## harness 本轮抓到并修掉的自身 bug

1. **模板题 ID 撞车**：两个主题共享同一封首金标信 → 生成的题目 ID 相同，结果互相覆盖（"Sommer" 和 "Jesuiten in Bayern" 撞上）。改用主题 ObjectId 后缀作 ID。
2. **"编造引用"误报**：regest/CMIF 原文本身会引用其他信件编号，模型转述时被误判为编造。断言细化为：来源文本里出现过的编号 = 回声（警告），凭空出现的才硬失败。

## 未解 / 待办

1. 精确度 49.5% 再往上要靠 cross-encoder rerank（Python sidecar）——先等人工评分确认必要性
2. 回答内容质量人工评分（review-latest.md）
3. 原文转写的 chunk 级检索索引（现在只做证据展示，不参与检索）
4. 多语言支持（已明确弃权）

## 第三轮（人工评分反馈后）

人工审阅 59 题：~54 题 gut；2 题 falsch 均为**"检索找对了、模型不认"**——de_variant_frage60（25851 在上下文里却答"无一封提及 Frage 60"）、Falsche Apostel（33960 挂着标签却被否认）；2 小毛病（列举截断 + 一处方向反；person_12 引用召回 0% 是金标方括号误报）。

| # | 根因 | 修法 |
|---|---|---|
| 11 | 25851 按 cosine 排第 55/57 位，模型读到末尾已下结论 | 关键词命中按匹配特异性排序，embedding 兜底垫后 → 25851 排第 1 |
| 12 | 33960 的命中标签埋在 42 个标签里 | 每封信加 `Treffer: 原因`；命中问题的标签单独提前一行；其余最多 12 个 |
| 13 | 模型习惯性以"keine Informationen"开头再自相矛盾，prompt 改三版无效 | 规则 3 重写 + **误拒答确定性重试护栏**（同引用护栏形态） |
| 14 | 列举截断（25/42）、方向反 | 规则 7 要求列全 + 注意 Von/An；max_tokens 8192 |
| 15 | mustInclude 题无生成端检查（Frage 60 因此漏网） | harness 对 mustInclude 也算 citation recall / 误拒答 |

| 17 | 人物金标不认 "[Name]" 括号变体（person_12 误报 0%） | 括号全清除 + 变体匹配；空金标题跳过（题集 50→49） |

**结果（58 题）**：引用召回 96.4% → **99.7%**；Frage 60、拉丁译本必含信均已引用；误拒答 0；模板题召回 100% / 精确 53.2%；全德语、零编造、零 intern 泄漏。

## 第四轮（2026-08-28）：rerank + 原文 chunk 索引 + 闭合查询

| # | 改动 | 说明 |
|---|---|---|
| 18 | **原文转写 chunk 级索引**（`npm run build:chunks`） | 2,215 封转写 + 编辑注释切成 16,843 段（800 字符/150 重叠，只索引公开信）；命中段落并入候选，**上下文和 UI 显示命中的那一段**而非开头 1500 字符 |
| 19 | **Cross-encoder rerank sidecar**（`rerank/`，bge-reranker-v2-m3） | 只给 embedding 额外补进来的信打分，低于 0.3 丢弃；关键词命中永不动。sidecar 不在线自动跳过 |
| 20 | 阈值校准（`test/calibrateRerank.js`） | 51 道金标题的 632 封额外信**零金标**、rerank 中位数 0.005 / p90 0.78 → 取 0.3。诚实说明：金标来自标签，测不出"未打标签但相关"的信，所以不砍光 |
| 21 | **闭合查询关闭模糊路径** | "X 写给 Y"/年份/Brief 编号命中时不再补 embedding 或段落——首跑时段落把转写里提到人名的信拉进来，人物题精确度反降 10–20 点 |
| 22 | 踩坑 | sentence-transformers ≥3 自带 sigmoid，再叠一层全部 0.500；首版给全部 hits 打分一题 5–10 秒——改为只打分额外信（≤20 封） |

**结果（58 题）**：模板题精确度 **53.2% → 76.8%**（召回 100% 不变）；德文枚举精确 86.8% → **95.8%**；Olevian 题 11 → 4 个来源；引用召回 99.2%；全德语、零编造、零 intern 泄漏、对抗题全部正确。

**仍未解**：评测题集偏向标签可达的问题，测不出 embedding/段落路径对"内容型问题"的价值——下一步可以建一小组"regest 有、标签没有"的内容型金标题来补这个盲区。
